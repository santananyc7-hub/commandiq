# COMMANDIQ BY REVENUE LABS
## Internal Financial Operations Command Center
### GStack Build Prompt for Claude Code

You are building a premium internal financial operations platform called:

# CommandIQ
### by Revenue Labs

CommandIQ is an internal financial operating system for a multi-million-dollar retail business.

The first live implementation is for Torches NYC, operated by Polanco Brothers Corp.

This is NOT a generic accounting dashboard.

This product should act like a financial command center for ownership and management.

Its job is to answer:

- How much cash do we actually have available?
- What obligations are due?
- Which vendors are creating risk?
- What changed financially?
- Where are expenses accelerating?
- What should management do next?
- Can we afford a purchase or initiative?
- Are we on pace to hit monthly revenue goals?
- What deserves immediate attention today?

The product should turn QuickBooks financial data into operational decisions.

The initial MVP should use QuickBooks as the primary live integration.

Do not require users to upload contracts during onboarding.

Contracts, debt agreements, leases, and obligation intelligence may become future modules.

# 1. DEVELOPMENT METHODOLOGY

Use the GStack methodology throughout the build.

Operate in this sequence:

1. PLAN
2. DESIGN
3. BUILD
4. VERIFY
5. REFINE

Do not rush immediately into implementation.

Before coding:

- inspect the repository
- identify the existing framework
- identify installed dependencies
- inspect environment variables
- inspect current routing
- inspect authentication
- inspect data models
- inspect any existing brand assets
- inspect available MCP/connectors
- inspect whether Higgsfield MCP/connector is available
- inspect whether QuickBooks credentials/integration scaffolding already exists

Do not unnecessarily replace working architecture.

Prefer incremental, production-ready changes.

After each major phase:

- run lint
- run typecheck
- run build
- test critical paths
- repair errors before moving forward

# 35. FINAL PRODUCT PRINCIPLE

CommandIQ should not tell management:

"Here is your financial data."

It should tell management:

"Here is what changed."

"Here is why it matters."

"Here is what you should look at."

"Here is what happens if you do nothing."

"Here is the next decision."

That distinction is the entire product.
